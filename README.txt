致理．心夥伴－活動報名系統 V11.21.9 正式整合版
更新時間：2026/09/15 21:00（台灣時間）

一、檔案內容
1. Code.gs：Google Apps Script 後端完整檔案
2. index.html：GitHub Pages 前端主頁
3. app.js：GitHub Pages 前端程式
4. app-custom.css：GitHub Pages 前端樣式
5. verify_*.js：本機驗證程式，不需上傳 GitHub 或 GAS

二、建議更新順序
1. 先以 Code.gs 全部取代 GAS 專案現有檔案，儲存後部署「新版本」。
2. 確認 GAS 網頁應用程式網址仍與 app.js 最上方 GAS_API_URL 一致。
3. 再將 index.html、app.js、app-custom.css 上傳 GitHub，覆蓋同名檔案。
4. GitHub Pages 部署完成後，以無痕視窗確認導覽列顯示 V11.21.9。

重要：本版新增 getPublicDataPage、getPublicEventDetails、getAdminFormOptions、getAdminLogs 端點，
務必先部署 Code.gs，再更新 GitHub 前端。後端仍保留舊版端點相容性。

三、V11.21.9 主要修正
- 學生報名專區初次只取得最近 8 項可報名活動，按「載入更多活動」才分批取得其他活動。
- 活動分類數量仍顯示全部可報名活動總數；活動詳情只更新該活動的資料與名額。
- 活動月曆改為點入時才載入完整公開活動，不拖慢報名專區初始畫面。
- 公開資料快取改為分段儲存，資料超過單一 GAS 快取大小時仍可使用快取。
- 冷啟動時，公開統計只讀取報名必要欄位；個管老師選單只讀取必要欄位。
- 報名送出前取消兩次額外請求，直接交由後端做最終身分、重複報名、容量與衝堂檢查。
- GAS 回應逾時時不重複送出報名；沿用相同 RegistrationId 查詢實際存檔結果。
- 有活動完全未勾選場次時，仍先顯示「返回檢查／放棄未勾選活動並送出」確認視窗。
- 登入成功後先顯示輕量快速入口，不自動載入全部活動、報名與過期資料。
- 「快速新增活動」只載入承辦人名單；「管理活動與報名」才載入完整管理資料。
- 動態紀錄改為切換頁籤時才讀取最近 100 筆。
- 帳密錯誤、網路中斷與 Google 回應逾時使用不同訊息。
- 長時間處理會顯示已等待秒數與勿重複點擊提示。
- 活動存檔逾時後不盲目重送；保留表單內容並先查核 EventId。
- 新增成功後直接更新本頁資料，不再強制等待整份後台資料重載。

四、保留不變
- 不新增或更動任何試算表欄位。
- 容量、一對一、多場次、系列活動與衝堂判斷規則不變。
- LINE 通知及 Google 行事曆邏輯不變。
- V11.21.8 的未勾場次確認、防重複報名與手機版報名說明收合均保留。
- 不新增「最多選三門」的文字或限制提示。

五、上線後必要測試
1. 無痕開啟報名專區：應先顯示最近 8 項；有更多活動時出現「載入更多活動」。
2. 點活動詳情、勾選活動、進入報名表單，確認手機與桌機顯示正常。
3. 選多項活動並讓其中一項完全不勾場次，確認兩個選項皆符合預期。
4. 以測試學生報名，確認容量、重複報名與衝堂仍由後端正確阻擋。
5. 登入後應先看到「快速新增活動／管理活動與報名」，不應先等待完整清單。
6. 快速新增一筆未公開草稿；再載入管理清單確認資料存在且不重複。
7. 點「動態紀錄」後才載入最近紀錄；帳密錯誤與斷網／逾時訊息應可區分。
